# 設計: Kapit-Mueller 模型のパートン平均場 VMC 対応

作成 2026-08-26 / ブランチ `parton-mode`

## 0. 目的

Julia-mVMC のパートン平均場モードに **Kapit-Mueller (KM) 模型**を追加し、

- φ = 1/2, ν = 1/2(硬芯ボソン、F = 2)
- φ = 1/3, ν = 1/3(フェルミオン、F = 3)

の 2 つの FCI について、**ED のエネルギーにどれだけ迫れるか**を測る。

既存の checkerboard 模型(`cb_nu12_boson`)と同じ検証層(P0 = ED 基準値 /
P1 = 1 体ハミルトニアン一致 / P2 = QP 並進共変性)を KM でも敷く。

## 1. 確定した物理設定

### 1.1 模型

正方格子 Lx × Ly(1 セル 1 サイト、`isite = Lx·y + x`、0-based)。ホッピングは

```
t(z) = W(z) · G(z)
W(z) = exp(−(π/2)(1 − φ)|z|²) · (−1)^(x + y + xy)      z = (x, y) = 変位
G(z) = exp(iπ φ · y · (2·x_start + x))                  Landau ゲージ
```

- **打ち切りは第 3 近接まで**(d² = x² + y² ≤ 4)。φ=1/2 で残差 ~4%、φ=1/3 で ~1.5%
- **ゲージは Landau**(元 ED コードの `String_Gauge` ではない)。非整合フラックスを
  入れない今の用途では巻き付き補正が不要で、後述の 2 つの性質が Landau でしか成り立たない
- 相互作用は**最近接ボンドの斥力 U**(元 ED の `IP.U` と同義)。ν=1/2 は U = 0
  (硬芯拘束のみ)、ν=1/3 は U = 7.0

### 1.2 ボンド列挙 — 変位和方式(元 ED からの意図的な変更)

元 `ModuleParentHamKM.jl` の `select_minimum_bonds` は、同じ端点対に落ちる複数の
変位のうち **1 本だけ**を残す。これは**対蹠変位で並進対称性を壊す**:

> 実測(2026-08-26 スパイク): 9×4・φ=1/3 で厳密並進が `{(0,0),(3,0),(6,0)}` の
> 3 本しか残らず、**T_y が落ちる**。Ly=4 では dy=+2 と dy=−2 が同じ端点対に落ち、
> どちらを残すかが並進で揃わないため。

本実装は**同じ端点対に落ちる全変位の振幅を足し合わせる**。これは打ち切り KM の
物理的に正しい構成であり、並進対称性が完全に回復する(9×4 で 12 本 = ⟨T_x³, T_y⟩)。

**ED 側もこの規約で書く**(新規実装なので互換の縛りがない)。旧 KM コードとの
一致検証は行わない — 代わりに§4 の物理検証(エルミート性・一様フラックス・
Chern 数・並進群)で正しさを保証する。

### 1.3 パートン構成

物理粒子を F 個のパートンに分解する(ν = 1/F、F 偶数 = ボソン / 奇数 = フェルミオン)。
各パートンが見るフラックスは

```
φ_f = φ / F        Σ_f φ_f = φ
```

このとき φ_f の KM 平均場の**最低 C = 1 バンドがちょうど N 粒子で充填**される
(N = ν·φ·Ns = φ_f·Ns)。Landau ゲージでは

```
G(z; φ/F)^F = G(z; φ)          ← 厳密に成立(実測 true)
```

なので、F 枚のパートン平均場の積が**物理 H と同じゲージの φ を厳密に再現**する。
String ゲージ・対称ゲージではこれが成り立たない。

### 1.4 格子サイズの制約

Landau ゲージで素の並進が生き残る条件は **φ·Lx ∈ ℤ**(巻き付きで始点の x が Lx 飛ぶ)。
平均場側にも同じ条件が要るので **Lx は F/φ = F·q の倍数**:

| 対象 | φ | F | F·q | Lx |
|---|---|---|---|---|
| ν=1/2 | 1/2 | 2 | 4 | 4, 8 |
| ν=1/3 | 1/3 | 3 | 9 | 9, 18 |

6×6・φ_f = 1/9 は `max|H − H†| = 0.106` で**非エルミートになる**(実測)。使えない。

### 1.5 対称群(実測で確定)

| | 物理 H | 平均場 (φ/F) | QP 群 = 剰余 |
|---|---|---|---|
| ν=1/2, 4×4 | ⟨T_x², T_y⟩ = 8 | ⟨T_y⟩ = 4 | **2 = F** |
| ν=1/2, 4×6 | ⟨T_x², T_y⟩ = 12 | ⟨T_y⟩ = 6 | **2 = F** |
| ν=1/3, 9×4 | ⟨T_x³, T_y⟩ = 12 | ⟨T_y⟩ = 4 | **3 = F** |
| ν=1/3, 9×5 | ⟨T_x³, T_y⟩ = 15 | ⟨T_y⟩ = 5 | **3 = F** |

- **α の idx クラス = ⟨T_y⟩ の軌道**。クラス数はフレーバーあたり約 6·Lx
- **QP 並進 = {T_x^{0}, T_x^{q}, …, T_x^{(F−1)q}}**、位数 F = 期待されるトーラス位相縮退
- 平均場は x 方向の並進を**全破れ**にする(拡大セルが x 方向に Lx サイト全部)

### 1.6 対象系

| 対象 | 格子 | N | N_φ | ED 次元 | 統計 | U |
|---|---|---|---|---|---|---|
| ν=1/2 | 4×4 | 4 | 8 | 1,820 | 硬芯ボソン | 0 |
| ν=1/2 | 4×6 | 6 | 12 | 134,596 | 硬芯ボソン | 0 |
| ν=1/3 | 9×4 | 4 | 12 | 58,905 | フェルミオン | 7.0 |
| ν=1/3 | 9×5 | 5 | 15 | 1,221,759 | フェルミオン | 7.0 |

6×6(ν=1/3)は §1.4 により Landau ゲージでは不可。正方トーラスが要る段階で
3×3 周期ゲージを別途構成する(後段、本設計の範囲外)。

### 1.7 自己交換ペア(Ly = 4 のときだけ発生)

Ly = 4 では変位 (0, ±2) が対蹠になり、**T_y² が端点を入れ替える**。この端点対は
α が実数でないと並進共変にできない(複素 α だと `H[i,j] = conj(α t) ≠ α t`)。

| 格子 | 自己交換ペア / 全ペア |
|---|---|
| 4×4 | 8 / 80 |
| 4×6 | **0** |
| 9×4 | 18 / 198 |
| 9×5 | **0** |

**対処**: fixture が自己交換クラスを検出し、**そのクラスの α を OptFlag = 0 で凍結**
する(係数は φ/F の KM 値そのままなので、凍結しても平均場は正しい位置にいる)。
凍結数は返り値で報告する。コア・パーサには手を入れない。

> なぜコアで検出しないか: コアは pmftrans/pmfpara しか見えず、⟨T_y⟩ が対称群である
> ことを知らない(qptransidx には QP 要素 = T_x^q しか入らない)。判定できるのは
> fixture だけ。

## 2. アーキテクチャ

コア(`MVMCOptimizers.jl` / `MVMCExpertModeParsers.jl`)には **模型依存が 1 箇所も無い**
(`cb_` 参照 0 件)。したがって変更はコアの外に閉じる。

### 2.1 mVMC 側

```
test/physics/
  lattice_model.jl      ← 新規。模型インターフェース(抽象)
  checkerboard_model.jl ← 既存。インターフェースに適合させる(既存 API は残す)
  km_model.jl           ← 新規。KM 模型
  parton_fixture.jl     ← 模型を引数で受け取るよう一般化
```

インターフェース(`AbstractPartonLattice`)が提供するもの:

| 関数 | 意味 |
|---|---|
| `pl_nsite(m)` | サイト数 |
| `pl_site_to_xy(m, i)` / `pl_xy_to_site(m, x, y)` | サイト番号 ⇄ 座標 |
| `pl_bonds(m)` | 無向ボンド `(i, j, dx, dy, d²)`(片方向、係数は別引き) |
| `pl_hopping(m, i, j, dx, dy)` | ボンドのホッピング係数(**端点込み**で決まる) |
| `pl_mf_hopping(m, i, j, dx, dy, F)` | 平均場係数(KM は φ/F、cb は物理と同じ) |
| `pl_cell_class(m, i, ex, ey)` | 拡大セル/対称群の軌道ラベル |
| `pl_translations(m)` | 平均場が保つ並進のサイト置換 |
| `pl_qp_translations(m, F)` | QP 射影に使う並進(剰余代表)と重みラベル |
| `pl_nn_pairs(m)` | 最近接ペア(物理 U 用) |

**checkerboard と KM の本質的な差**は `pl_hopping` が端点に依存するかどうか:
cb は始点の行の偶奇 `y0` のみ、KM は始点の x 座標(Landau ゲージ)。既存 fixture の
`cb_hopping(p, dx, dy, y0)` を `pl_hopping(m, i, j, dx, dy)` に一般化して吸収する。

**リファクタの安全網**: `test/physics/` の P 層 442 テストが checkerboard 側の
ビット一致を守る。抽象化の前後で `runtests.jl` が全緑であることを確認する。

### 2.2 run 出力

`playground_nozomi/km/`(git 管理外)。scripts は `cb_nu12_boson/scripts/` の
`gen_def.jl` / `chain.jl` / `stage_io.jl` / `analyze.jl` を KM 向けに移植する。

### 2.3 ED 側(別リポジトリ `/home/nozomihigashino/ED`)

新モジュール `Code/test/ExactDiagonalization/` に追加する。

```
src/
  statistics.jl   ← 新規。AbstractStatistics: Fermion / HardcoreBoson
  lattice.jl      ← KapitMuellerLattice(Lx, Ly) を追加
  model.jl        ← KapitMuellerModel(φ, hopmax, U, V, R) を追加
  system.jl       ← KapitMuellerSystem を追加
  terms.jl        ← KM の build_terms
  engine.jl       ← jw_sign を統計でディスパッチ

```

**統計軸**: `engine.jl` の `check_sign` 呼び出しを `hop_sign(statistics, …)` に置換し、
`Fermion` は現行の JW 符号、`HardcoreBoson` は `+1` を返す。既存フェルミオン経路は
**ビット一致**(既存 13 テストが守る)。

**出力**: `Data/ExactDiagonalization/SingleLayer/KapitMueller/Lx=..-Ly=..-N=..-mode=total/phi=..-U=..-V=..-hopmax=../`
に JLD2(`EDResult`)。加えてプロジェクト規約の `.dat`(スペース区切り・`#` ヘッダ)で
低エネルギースペクトルを出す。

## 3. 平均場アンザッツ

### 3.1 既定: φ/F 焼き込み(方式 P)

- `pmftrans` に φ_f = φ/F の KM ホッピングを固定係数として入れる
- `pmfpara` の idx = ⟨T_y⟩ 軌道 × フレーバー群
- α の初期値は**全 idx で 1.0**(`InPmfPara.def` 相当を 7 列で明示)
- 自己交換クラスは OptFlag = 0 で凍結

初期状態が既にギャップの開いた C = −1 の正しい位相にあり、**占有集合が一意に決まる**。
checkerboard で最大の障害だった seed 不安定性(離散的な占有選択の分枝)を構造的に回避する。

### 3.2 比較軸: 全ペア(方式 Q、後段)

`graph = :full` 相当(全サイト対、係数 1、α に全部持たせる)。表現能力の天井を測る。
第 1 段の結果が出てから投入を判断する。

### 3.3 フレーバー群

`sym`(全フレーバー同一)/ `indep`(独立)。ν=1/3 は `2+1` も。
既定は **`sym`** — φ/F 焼き込みでは全フレーバーが同一の平均場を見るのが自然。

> **`PartonFlavorSymFast` は 0 を書く**(既存の規律)。`PartonOccMode = 1`(MOM)と
> 両立しないため。

## 4. 検証戦略

| 層 | 内容 | 判定 |
|---|---|---|
| K0 | KM 1 体 H のエルミート性 | `max|H − H†| < 1e-12` |
| K1 | プラケットフラックスが一様 φ | 全プラケットで一致(mod 1) |
| K2 | 厳密並進群が §1.5 の表と一致 | 本数と要素が一致 |
| K3 | 平均場の最低バンドが N でちょうど充填・ギャップあり | gap > 0.1 |
| K4 | 平均場の最低バンドの Chern 数 | **C = −1**(ツイスト Berry 位相) |
| K5 | フレーバー積 `G(φ/F)^F == G(φ)` | 厳密一致 |
| P0 | ED 基準値(4 系) | 新規計算し `test_p0_ed_reference.jl` に登録 |
| P1 | mVMC 側 `km_onebody` と ED 側 1 体 H の一致 | `1e-10` |
| P2 | QP 並進が物理 H と平均場を保つ | 置換で厳密一致 |
| R | checkerboard の P 層 442 テストが全緑のまま | リファクタ前後で不変 |

K0〜K5 はスパイクで**全て実測済み**(2026-08-26)。実装後に自動テストとして固定する。

## 6. 決めたこと(判断ログ)

| 判断 | 理由 |
|---|---|
| Landau ゲージ | フレーバー積 `G(φ/F)^F = G(φ)` が厳密に成立するのは Landau だけ |
| 変位和方式 | `select_minimum_bonds` は対蹠変位で並進対称性を壊す(実測) |
| Lx を F·q の倍数に | φ·Lx ∉ ℤ だと平均場が非エルミートになる(実測 0.106) |
| ν=1/3 は 9×4 / 9×5 | 6×6 は §1.4 で不可。正方トーラスは後段 |
| 自己交換クラスは凍結 | コアは ⟨T_y⟩ を知らないので検出できない。fixture の責務 |
| ED は新モジュールに追加 | 型階層・検証・出力規約がそのまま使える |
| 模型抽象はインターフェース抽出 | fixture の「血で贖った」ロジックを 1 本に保つ |
